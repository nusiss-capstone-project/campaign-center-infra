# Linkerd identity materials (example layout)

Copy to `linkerd.<env>/` (gitignored). Files are auto-generated by
`install-linkerd.sh` if missing:

- `ca.crt` / `ca.key` — trust anchor (ECDSA P-256)
- `issuer.crt` / `issuer.key` — identity issuer

```bash
# usually not needed — install script generates these
./ansible/scripts/install-linkerd.sh dev
```

Do not commit private keys.
